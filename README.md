# 🎬 Movie Search App

A simple Movie Search Web Application built with **HTML, CSS, and JavaScript** using the **OMDb API**.

## Features

* Search movies by title
* Display movie poster
* Show movie rating and year
* Simple and responsive interface

## Technologies

* HTML
* CSS
* JavaScript
* OMDb API

## How to Run

1. Get a free API key from https://www.omdbapi.com/
2. Replace `YOUR_API_KEY` in `script.js`
3. Open `index.html` in your browser
